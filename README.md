# SocialSphere

SocialSphere is a responsive front-end social media application. This project was built as part of a CSS frameworks assignment, with the main goal of applying **Tailwind CSS** to create a structured, responsive, and scalable user interface.

## 🌟 Features

- **Responsive Design:** Works seamlessly across mobile, tablet, and desktop screens.
- **Post Feed:** View posts with images and captions.
- **User Sidebar** View profile in sidebar.
- **Modern UI:** Clean and intuitive layout built entirely with Tailwind CSS.

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **Tailwind CSS**
